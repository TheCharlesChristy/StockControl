# Profile

## Who can use this page?

Every signed-in user can open Profile by selecting their avatar or signed-in identity in the
navigation drawer.

## Manage your photo

1. Select **Choose photo**.
2. Choose a PNG or JPEG image.
3. Wait for **Profile photo saved.**

If a photo is already set, select **Remove** to return to initials. Your display name, email, and
role are managed by an Admin from [Team & access](team-and-access.md); they are not editable here.

If the upload fails, keep the page open and read the error message. Try a supported image or report
the problem using [Report an issue](report-an-issue.md).
