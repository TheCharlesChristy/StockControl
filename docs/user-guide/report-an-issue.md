# Reporting an issue

## Who can use this feature?

Every signed-in user can report an issue from the top bar. The report automatically includes the page
you were viewing so the team can identify the context.

## Submit a report

1. Select **Report an issue**.
2. Enter a short summary in **Title**.
3. In **What happened?**, include:
   - what you expected;
   - what actually happened;
   - the steps that reproduce it;
   - the item, job, or user involved, without including passwords or secrets.
4. Select **Submit issue**.

After submission, StockControl confirms **Issue reported** and provides an **Open GitHub issue** link.
Select **Close** when finished.

If the report cannot be submitted, read the error and try again. If the problem prevents reporting,
give the details to your administrator through your normal support channel.
