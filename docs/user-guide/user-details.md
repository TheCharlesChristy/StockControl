# User details

## Who can use this page?

User details is Admin-only and opens from Team & access. It combines account maintenance with a
summary of the person’s work.

## Review the summary

The page shows whether the account is Active or Disabled and counts:

- Stock movements
- Open reservations
- Requests waiting

The page also contains Recent activity, Open reservations, and Stock requests for that person.

## Edit account details

In **Details**, an Admin can change:

- Username
- Work email, which is optional; emptying the field removes the address
- Name
- Role, except for their own account
- Account is active, except for their own account

Select **Save changes**. Profile photos can be added with **Choose photo** or removed with **Remove**.

Changing a person’s role or disabling them affects access immediately. Their history is not rewritten.

## Review activity

Recent activity shows the person’s latest stock movements. Select **See the full log** to open
[Transactions](transactions.md) filtered to that actor.

Open reservations show Reserved, Collected, and Outstanding quantities. Stock requests can be reviewed
from this page using the same approval, rejection, and withdrawal controls described in [Stock requests](stock-requests.md).

## Delete an account

Select **Delete**, read the confirmation, and select **Delete account** only when appropriate. An
account can be deleted only if the person has never recorded stock activity. If they have worked in
StockControl, disable the account instead; history must never be erased.
