# Team & access

## Who can use this page?

Team & access is Admin-only. Office and Engineer users who try to open it see **Access restricted**.
Roles are fixed: Engineer, Office, and Admin. There are no per-user permission overrides.

## Find a person

Use **Search the team** to search by name, email, or role. The table shows name, email, role, created
date, and whether the account is active. Select a person’s name to open [User details](user-details.md).

## Create a user

1. Select **New user**.
2. Enter **Work email** and **Name**.
3. Choose a **Role**.
4. Set an **Initial password** of 15–128 characters. A unique passphrase is a good choice.
5. Select **Create user**.

Tell the person their initial password securely. StockControl does not send an invitation or password
email.

## Change a role

1. Choose a role from the person’s inline Role selector.
2. Read the confirmation dialog.
3. Select **Change role**.

The new role applies to subsequent requests and open browser activity follows the updated permission.
You cannot change your own role.

## Disable or enable an account

1. Toggle the person’s **Active** switch.
2. Read the confirmation.
3. Select **Disable** or **Enable**.

Disabling ends the person’s active sessions immediately and blocks new sign-ins. Their stock history,
reservations, and requests remain intact. You cannot disable yourself.

For a person with existing stock history, disable the account rather than deleting it. Use [User details](user-details.md)
for the deletion rules.
