# Overview

The Overview is the first page after sign-in. It changes to match the person signed in rather than
showing the same dashboard with controls removed.

## Engineer view

The Engineer Overview is a working stock list:

- Use the **Search inventory** field to search by item code, name, barcode, or manufacturer part
  number.
- Select the arrow beside an item to show its stock by location.
- Use the page controls to move through the catalogue.
- Select an item code to open [Item details](item-details.md).
- Review **Your jobs** to open an assigned job and see stock already at its site.
- Review **Stock committed for you** to see reservations and outstanding quantities.
- Review **Your stock requests** to see requests you have submitted and their status.

The Engineer view does not show business-wide low-stock totals, the full activity feed, or the
Office request queue.

## Office and Admin view

Office and Admin users see the decisions that need attention:

- **Low on stock** links to items below their configured low-stock minimum.
- **Stock requests** links to the request queue and shows pending demand.
- **Jobs coming up** links to the Jobs page.
- **Stock waiting to be collected** shows open reservations. Use its toggle to focus on your own
  reservations or see the wider queue.
- **Recent activity** shows the latest stock changes and links to the full [Transactions](transactions.md)
  page.

Select an item, job, or request link to move directly to the relevant workflow. Use the page
sections as a work queue: resolve pending requests, check low stock, then review upcoming jobs and
reservations.

## After a change

Pages reload their relevant data after a successful action. If a list is empty, use the link or
page action suggested in the empty state. For example, create an item from [Inventory](inventory.md)
or ask for stock from [Item details](item-details.md).
