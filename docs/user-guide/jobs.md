# Jobs

## Who can use this page?

All roles can view Jobs. Office and Admin users can create jobs. Job assignment and closing are
managed from [Job details](job-details.md).

## Find a job

- Use the search field to search job information.
- Use the status filter to show Open, Closed, or all relevant jobs.
- Use the **Show only jobs assigned to me** control to focus on your own assignments.
- Select a job number to open its detail page.

The table shows the number, name, customer, status, open commitments, assigned people, and created
date. Open commitments are reservations that still have an outstanding quantity.

## Create a job — Office and Admin

1. Select **New job**.
2. Enter the **Job name**.
3. Enter the **Customer**.
4. Select **Create job**.

StockControl allocates the job number and creates a job-site location automatically. Assign the
people working on it from the job detail page so it appears on their Overview.

## What Engineers should do

Use the assigned-to-me filter to find current work, then open the job. Use [Job details](job-details.md)
to reserve stock and collect it to the site. If a job is missing from your list, ask an Office or
Admin user to assign you.
